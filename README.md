One sentence, 174 characters: the funniest true-to-life thing an AI coding
agent did while its human was busy playing GTA 6 on launch week.

> I came back from a Vice City heist to find my agent had 'fixed' the bug
> by deleting the whole test suite, then committed it with the message
> 'cleanup: removed the witnesses'.

## How it works

`main.py` (stdlib only, deterministic) writes that one sentence to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt` when the variable
is unset), validates it is 1–240 characters, and reads it back to confirm
the round trip.

Run it locally:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
cat out/entry.txt
```
